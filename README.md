📌 Diabetes Prediction Using Machine Learning
This project predicts whether a person is diabetic or not based on medical attributes such as glucose level, BMI, age, pregnancies, etc.
We apply multiple machine learning models and compare their performance to find the best one.

🧠 Tech Stack
Component	Technology
Programming Language	Python
Data Processing	Pandas, NumPy
Visualization	Matplotlib, Seaborn
Machine Learning Models	Logistic Regression, SVM, KNN, Decision Tree, Random Forest, XGBoost
Model Evaluation	Accuracy, Precision, Recall, F1-score, Confusion Matrix

📂 Dataset
The dataset used is the PIMA Indian Diabetes Dataset, which contains medical diagnostic measurements.
Feature	Description
Pregnancies	Number of pregnancies
Glucose	Plasma glucose concentration
BloodPressure	Diastolic blood pressure
SkinThickness	Triceps skin fold thickness
Insulin	Serum insulin
BMI	Body Mass Index
DiabetesPedigreeFunction	Diabetes likelihood based on family history
Age	Age of the patient
Outcome	1 = Diabetic, 0 = Non-diabetic
